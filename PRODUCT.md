# Product

## Register

product

## Users

Kuala Lumpur residents reporting suspected dengue breeding habitats, plus public viewers using the awareness map and status flows. Residents use the app on phones in the field, often outdoors, with limited time and variable lighting. A prototype officer console exists in the repository, but it is out of scope for the assessed implementation and should not drive architecture or acceptance claims.

## Product Purpose

DengueWatch lets residents submit photo evidence of likely mosquito breeding habitats, confirm the exact map location, and track progress anonymously. The same system also exposes a public awareness map and public report detail/status views. Success means faster high-quality reporting and trustworthy public awareness mapping without overstating the scope of any unfinished operational tooling.

## Brand Personality

Clear, civic, dependable. The interface should feel like a field-ready public health tool: calm, map-led, high-contrast, and operationally credible on both phone and laptop.

## Anti-references

Avoid generic SaaS dashboards, warm editorial serif branding, decorative gradients that compete with task content, and playful consumer-social patterns that would weaken trust in a public-health workflow.

## Design Principles

1. Put the task first: primary actions and current state should be visible immediately.
2. Make public-health trust legible: privacy boundaries, consent, and status must read clearly.
3. Keep the resident flow calm and direct: each step should reduce uncertainty, not add chrome.
4. Keep public context dense but stable: map, evidence, consent, and status should scan quickly.
5. Use one civic visual language across resident mobile and public web surfaces.
6. Prefer a map-and-data atlas feel over marketing-style panels or layered decorative shells.

## Accessibility & Inclusion

Target WCAG AA contrast. Maintain large touch targets on resident mobile flows, strong text readability in outdoor-light conditions, keyboard accessibility for public desktop pages, and reduced reliance on color alone for statuses and warnings.
